# System Health Monitor

A Bash-based Linux system health monitoring project.

## Project Goal

The goal of this project is to build a Linux system health monitoring utility using Bash scripting.

The monitor will collect and report important system information such as:

- CPU usage
- Memory usage
- Disk usage
- Running processes
- System uptime
- Filesystem status

## Learning Scope

This project is being developed as part of my DevOps and Cloud Engineering learning journey.

The initial version is based on:

- Linux Fundamentals
- Linux system administration
- Bash scripting
- Text processing
- Process management
- Filesystem management
- Logging
- Performance monitoring
- Cron scheduling
