# 🖥️ Linux System Health Monitor

> A Bash-based Linux system monitoring project developed as part of my **DevOps and Cloud Engineering learning journey**.

The goal of this project is to understand how Linux exposes system information and how Bash can be used to collect, process, and report system health metrics.

The project is being developed **incrementally** — each feature is first explored manually using Linux commands, then implemented in Bash, tested, modularized, documented, committed with Git, and pushed to GitHub.

# 🎯 Project Objective

The objective is to build a practical Linux system health monitoring utility using **Bash scripting**.

The project is also being used to develop practical knowledge of:

- Linux system administration
- Bash scripting
- Linux `/proc` filesystem
- CPU and memory monitoring
- Text processing
- Error handling
- Modular scripting
- Git
- GitHub
- DevOps workflows
- Automation
